#  Weather Dashboard

A modern and responsive weather dashboard built using React.
It provides real-time weather data, interactive charts, and a clean glassmorphism UI.

##  Features

*  Search weather by city
*  Real-time temperature & conditions
*  Hourly temperature & humidity charts
*  5-day forecast sidebar
*  Smart weather alerts
*  Modern UI with smooth animations
*  Fully responsive design

##  Tech Stack

* React.js
* Chart.js (react-chartjs-2)
* Framer Motion
* OpenWeather API
